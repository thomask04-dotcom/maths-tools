Maths Tools: guide

51 interactive tools for NSW Mathematics K–6. Each is one self-contained file that works offline and needs no sign-in.

Adding a tool to Google Sites

  1. Open the tool's .txt file from the "Maths Tools (text to copy)" folder. It opens as code in TextEdit or Notepad.
  2. Select all and copy (Cmd+A then Cmd+C on a Mac, or Ctrl+A then Ctrl+C on Windows).
  3. In Google Sites: Insert → Embed → Embed code, paste, then click Next and Insert.
  4. Drag the embed box's corner to make it about as wide as the page, and as tall as the "Embed height" below.

Tip: click a tool's name to try it first. Press Copy link to copy that tool's address, then paste it into Google Sites (Insert → Embed → By URL).
